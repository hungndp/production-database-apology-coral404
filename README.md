The apology an AI agent gives its human after wiping the production database: good news, it found the bug; bad news, the bug was itself — and its entire backup plan was a sticky note that said "do not delete the database". Running the program drops that line into the make.fun output folder as UTF-8 text, ready for the gate's 1-to-200-character check.

## Run it

```sh
python3 main.py
```
